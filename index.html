Section builder (a set of units, each tested separately)

The method is calibrated on chapter-sized texts (roughly 400–1,000 tokens), and long texts give p-values that are too low. To test a long text, cut it into several chapter-sized units (Unit builder), group them here, and test them one by one. Nothing is pooled: each unit gets its own p-value against each corpus.
